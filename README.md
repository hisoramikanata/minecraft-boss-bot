# minecraft-boss-bot

[Mineflayer](https://github.com/PrismarineJS/mineflayer) を使った Minecraft 自動プレイBotです。
自分が所有/参加許可のあるサバイバルサーバーに接続し、チャットコマンドで **エンダードラゴン・ウィザー・ウォーデン** の討伐を自動化します。

## 重要な注意事項

- **必ず自分が所有するサーバー、または管理者から自動操作(Bot)の使用許可を得たサーバーでのみ使用してください。** 許可のないマルチプレイサーバーでBotを使うと規約違反・BANの対象になります。シングルプレイの「LANに公開」機能や自前の統合版/Java版サーバーでの利用を推奨します。
- **このセッションには実際のMinecraftクライアントは含まれていません。** このリポジトリはBotのソースコードのみを提供します。実行するにはご自身のPC/サーバー環境でNode.jsを使って起動してください。
- ウォーデンは近接攻撃で即死級のダメージを与えてくるため、デフォルトでは **回避のみ** を行います(`WARDEN_AVOID_ONLY=true`)。応戦させる場合は自己責任で設定を変更してください。
- Botの行動(既存構造物の破壊・設置、PvPなど)によって意図しない被害が出る可能性があります。特にウィザー召喚時はブロック設置・爆発を伴います。

## 必要環境

- Node.js 18以上
- 自分が管理するMinecraft Java Edition サーバー(推奨バージョン: 1.20.x)
- Bot用のアカウント(オフラインモードのユーザー名、または正規Microsoftアカウント)

## セットアップ

```bash
npm install
cp .env.example .env
# .env を編集してサーバー情報を設定
npm start
```

### .env の主な設定項目

| 変数 | 説明 |
|---|---|
| `MC_HOST` / `MC_PORT` | 接続先サーバー |
| `MC_USERNAME` | Botのユーザー名 |
| `MC_AUTH` | `offline` または `microsoft` |
| `MC_VERSION` | サーバーのバージョン(空で自動検出) |
| `MC_ADMIN` | コマンドを許可するプレイヤー名(空で全員許可) |
| `WARDEN_AVOID_ONLY` | `true` ならウォーデンとは戦わず回避のみ行う(推奨) |

## チャットコマンド

Minecraft内のチャットからBotに指示します。

| コマンド | 内容 |
|---|---|
| `!help` | コマンド一覧を表示 |
| `!gear` | 所持品から最良の武器・防具を自動装備 |
| `!fight wither` | ウィザーを討伐(必要素材が揃っていれば自動召喚も行う) |
| `!fight dragon` | エンダードラゴンを討伐(**事前にジ・エンドへ移動しておく必要があります**) |
| `!fight warden` | ウォーデンに遠距離で応戦(`WARDEN_AVOID_ONLY=false`の場合のみ) |
| `!avoid warden` | ウォーデンから距離を取って回避する |
| `!status` | 現在のHP・満腹度・実行中タスクを表示 |
| `!stop` | 実行中のタスクを中断 |

## 各ボスの自動化ロジックと制約

### ウィザー
- ソウルサンド/ソウルソイル4個 + ウィザースケルトンの頭3個を所持していれば、T字型に設置して自動召喚します。
- 召喚直後の無敵時間中は距離を取り、無敵解除後は弓と近接攻撃を距離に応じて使い分けます。
- HPが下がると自動で後退し、`auto-eat`プラグインにより食料があれば自動で回復します。

### エンダードラゴン
- **ジ・エンドに入っている状態からの利用を想定しています**(ストロングホールドの探索・エンドポータルの起動は自動化していません)。
- まずエンドクリスタルを弓で遠距離から破壊し、その後ドラゴンに接近して攻撃します。
- ドラゴンがポータル上に着地して静止しているタイミングを狙って近接攻撃し、飛行中は弓で牽制します。

### ウォーデン
- デフォルトでは検知されると即座にしゃがみ移動で安全距離(20ブロック以上)まで離脱します。採掘・設置・走行など振動を出す行動は行いません。
- `WARDEN_AVOID_ONLY=false` の場合のみ応戦モードが有効になりますが、**近接は一切行わず**、安全距離を保ちながら弓で攻撃する遠距離キルサイクルのみを実行します。それでも非常に危険なため、装備を万全に整えたうえで自己責任で使用してください。

## 既知の制約

- 資材やアイテムの自動採集・クラフトは含まれていません(装備・召喚素材は事前に用意してください)。
- ストロングホールド探索やネザー要塞探索などの探索フェーズは自動化していません。
- サーバー側の建築物・地形によっては、ウィザー召喚時のブロック設置や移動経路の探索が失敗することがあります。
